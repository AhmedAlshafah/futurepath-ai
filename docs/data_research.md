##Data Analyst
Description: Business intelligence Analysts query data sources and produce reports to identify patterns and trends. O*NET Business Intelligence Analyst is a proxy for the broader "Data Analyst" job title

| Skill | Sugested weight | Evidence | 
| SQL | 3 | Mentioned in 35% of postings |
| Microsoft Power BI | 2 | 20% |
| Python | 2 | 20% |
| Tableau | 2 | 19% |
| Microsoft Excel | 2 | 17% |
| R | 1 | 10% |

Source: [O*NET In-Demand Technology Skills: Business Intelligence Analysts](https://www.onetonline.org/link/demand/15-2051.01) provides the posting percentages. [HRD Corp's Data Analyst report](https://hrdcorp.gov.my/wp-content/uploads/2021/03/1_2020_INDUSTRY-TRAINING-INTELLIGENCE-REPORT.pdf) also identifies SQL, Python, Power BI, Tableau, and Microsoft Office as relevant skills. O*NET describes the occupation as querying data repositories, producing reports, and identifying patterns and trends.

##Machine Learning Engineer
Description: Machine Learning Engineers build an deploy machine learning systems. O*NET does not provide an exact occupation match, so these skills use Machine Learning ENgineer posting research and a professional job descriptions.

| Skill | Suggested weight | Evidence |
| Python | 3 | Appears in 70% of the Machine Learning Engineer postings analyzed
| PyTorch | 3 | 38% | 
| MLOps | 3 | 27% | 
| TensorFlow | 2 | 17% |
| Docker | 2 | Listed for deploying containerized Machine Learning services |
| Kurbenetes | 2 | Listed for deploying containerized Machine Learning services |

Sources:[AI Open Roles' analysis](https://aiopenroles.com/insights/how-to-become-a-machine-learning-engineer/) reports skill frequencies from 827 Machine Learning Engineer postings. [Anduril'd Machine Learning engineer job description](https://job-boards.greenhouse.io/andurilindustries/jobs/5250787007?gh_jid=5250787007) names Python, PyTorch, TensorFlow, MLOps, Docker, and Kurbenetes. [Twilio's Machine Learning Engineer listing](https://jobs.twilio.com/careers/job/1099555992916?domain=twilio.com) provides additional evidence for Python, MLOps, containerzation, and Kurbenetes.

The AI Open Roles sample focuses on AI companies and may not represent the wider job market or entry-level requirements. The Docker and Kubernetes weights are provisional because the posting analysis does not give percentages for them.
